# UnityAgent Golden Regression

Canonical Eval turns accepted UnityAgent behavior into regression assets.

## Principle

- Golden Tasks preserve accepted behavior and decision boundaries.
- Exact generated-source equality is not the default grader.
- Deterministic outcome and invariant grading is preferred.
- Positive/negative boundary pairs prevent overfitting a policy into an absolute prohibition.
- `unavailable` is never counted as passed.
- Context Manifest / Execution Graph remain the trace used to diagnose failures.

## Validate suite

```bash
python Eval/Golden/validate_required_knowledge.py
python Eval/Golden/validate_golden_tasks.py
```

## Grade candidate results

```bash
python Eval/Golden/run_golden_evals.py --results Artifacts/GoldenEval/candidate-results.yaml
```

Candidate results are generated by the Runtime execution owner or a model-comparison harness. Eval itself does not invoke a model.

## Project Regression Graph

```bash
python Eval/Golden/project_regression_graph.py
python Eval/Golden/project_regression_graph.py --results Artifacts/GoldenEval/candidate-results.yaml
```

## Failure taxonomy

Canonical failure attribution is defined under `Eval/Attribution/` and preserves the distinction between observed Agent-quality failures and infrastructure/evaluator/evidence failures.

Generated summaries and graphs belong under `Artifacts/GoldenEval/` and are not canonical policy.
