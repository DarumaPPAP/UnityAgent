# UnityAgent Golden Regression

Phase 7 converts accepted UnityAgent behavior into regression assets.

## Principle

- Golden Tasks preserve accepted behavior and decision boundaries.
- Exact generated-source equality is not the default grader.
- Deterministic outcome and invariant grading is preferred.
- Positive/negative boundary pairs prevent overfitting a policy into an absolute prohibition.
- `unavailable` is never counted as passed.
- Context Manifest / Execution Graph remain the trace used to diagnose failures.

## Validate suite

```bash
python Tools/GoldenEval/validate_required_knowledge.py
python Tools/GoldenEval/validate_golden_tasks.py
```

## Grade candidate results

```bash
python Tools/GoldenEval/run_golden_evals.py --results Artifacts/GoldenEval/candidate-results.yaml
```

Candidate results are generated by the execution owner or model comparison harness. The runner itself does not invoke a model.

## Project Regression Graph

```bash
python Tools/GoldenEval/project_regression_graph.py
python Tools/GoldenEval/project_regression_graph.py --results Artifacts/GoldenEval/candidate-results.yaml
```

## Failure taxonomy

- routing_miss
- context_miss
- policy_violation
- harness_violation
- mutation_violation
- evidence_overclaim
- model_failure
- broken_eval
- unavailable_evidence

Generated summaries and graphs belong under `Artifacts/GoldenEval/` and are not canonical policy.
