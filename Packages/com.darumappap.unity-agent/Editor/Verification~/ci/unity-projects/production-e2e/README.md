# G1 Production E2E fixture

Independent, non-secret fixture pinned to **6000.3.12f1 / URP 17.3.0**. Package resolution and Editor compilation have not run in cloud. The Unity package registry returned HTTP 403 during preparation; the URP pin must be resolved on the licensed runner before calling this fixture verified. Do not fabricate a packages-lock.json before real Package Manager resolution.

Run the existing Control Plane `rock plan → rock approve → rock apply` against this fixture with a configured Blender MCP server. This produces external Staging `Rock.fbx` and `artifact.json`. Set `UNITYAGENT_G1_FBX`, `UNITYAGENT_G1_ARTIFACT`, `UNITYAGENT_G1_EVIDENCE`, then run Editor tests filtered to `UnityAgent.G1.RockProductionTests`. The isolated fixture's generated `Assets/UnityAgentRockG1` must be absent initially. Tests use Editor APIs for Unity assets. The scene is generated by the Editor, never raw YAML.

`RockProductionTests` is a native Editor validation harness. Passing it alone does not prove that the Production Runtime dispatched the complete Blender→Unity→QA workflow. The evidence aggregator also requires the Control Plane's durable job/evidence, matching revisions, visual review and rollback results. Play/Timeline MP4 decoding remains a separate #194 gate.

The test verifies URP and RenderGraph, import, shader/material, prefab/scene, geometry, missing scripts/references, reimport GUID/reference preservation, rendered pixels, bounded Editor Undo, with a separate Python staging/conflict gate. It restores scene setup and render settings. It operates only in the disposable fixture; use no real game project here.

Windows runner: Unity Editor **6000.3.12f1**, valid license, graphics device, Python with project dependencies, reviewed Blender MCP installation, same source revision for CLI and UPM. No runner or license is provisioned automatically. G2 and G3 require separately authorized projects/devices.
