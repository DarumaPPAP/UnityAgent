# Graph Observatory

Phase 8 foundation for UnityAgent observability.

## Purpose

Convert Context, Harness, Execution, and Regression data into inspectable graph artifacts.

## Planned Structure

```
Tools/GraphObservatory
├── schema
│   └── graph.schema.json
├── builder
├── frontend
└── artifacts
```

## Planned Views

- Architecture
- Task Explorer
- Execution Trace
- Regression Dashboard

The initial implementation is read-only. Policy and Harness changes continue to happen through canonical files and reviewed pull requests.
